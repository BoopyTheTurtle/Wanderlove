# Task pool

Status: approved by Edgar, October 1, 2026; every task is in `packages/core/src/quest/pool.ts`. Stage 4 of the [MVP roadmap](../mvp-roadmap.md). Written to the
[task design guide](../research/task-design-guide.md), whose template, tags, and checklist apply to every row.

The pool reaches the roadmap's targets: 30 introductory tasks, 60 silly games, 30 deep tasks, and 30 wrap-ups. Ids 001
to 010 in each category are the guide's worked examples (section 5) and stay there; this file adds 011 onwards, 110
tasks in all. Once Edgar signs a task off, it moves into the code pool in `packages/core`.

**How to review.** Strike or comment on any row by its id. The checklist in guide section 6 decides each row; one
"no" sends it back. The last checklist line, a try at a real stop, comes later with a test couple.

**Look at these first.** Each one stretches a rule, and each could go either way:

- `silly-050` asks partners to act as each other. It is fun when kind and hurtful when not; the prompt says "copy
  what you love", but the risk stays.
- `silly-059` has both partners stand on one foot. It needs flat ground and carries `move`, but a fall is possible.
- `deep-018` and `deep-026` touch the need beneath conflict, as the updated guide now allows: support when life gets
  busy, and a signal for "I'm here". Both stay in positive form.
- `deep-020` asks about a quiet dream. It skirts the guide's "no regrets" line by asking only for the dream and one
  way to help.
- `wrapup-012` asks when you found your partner attractive on the walk. It is a compliment, not a sex topic, but it
  is the closest the pool comes.
